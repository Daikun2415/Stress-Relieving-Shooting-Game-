# Stress-Relieving-Shooting-Game-
「ストレス発散​シューティングゲーム」​のプロジェクトファイルになります。

## ゲームプレイについて
「Stress-Relieving Shooting Game.exe」と「source」フォルダをインストールしていただき、exeファイルを起動するとプレイできます。

その際、「source」フォルダをexeファイルを置いた同じファイルに置くようにお願いします。

## 操作方法
マウス移動：銃を動かす、左クリック：弾を発射、右クリック：銃を反転

## Code Filesについて
「Code Files」はvisualStudioのソースコードのファイルになります。

「Main.cpp」を開いていただけばソースコードが表示されます。
